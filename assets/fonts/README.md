# Fonts for stamped PDFs

Noto Sans (Latin, Latin extended, Greek, Cyrillic), Noto Sans Devanagari and Noto Sans Arabic, regular weight,
from https://github.com/notofonts/notofonts.github.io. Licensed under the SIL Open Font License 1.1
(https://openfontlicense.org). They are embedded as subsets in the signed consent PDFs so a student or guardian
name in any of these scripts prints correctly. Add a font here, and to `src/infrastructure/pdf/fonts.ts`, to
support another script.
